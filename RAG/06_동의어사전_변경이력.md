> 이 파일은 검색용 지식 청크가 아니라, **쿼리 확장(query expansion)을 위한 보조 사전**입니다.
> `01~05` 파일의 각 항목에는 이미 `*(관련 검색어: ...)*` 태그가 직접 삽입되어 있으므로, 이 파일을 벡터DB/검색 인덱스에 그대로 넣지 마세요. 대신 챗봇이 사용자 질문을 받았을 때 아래 표를 참고해 검색 쿼리를 보강(동의어 치환)하는 전처리 단계에서만 사용하는 것을 권장합니다.

## ✅ 기존 홈페이지 챗봇("독립이") 대비 호환성 검증 (2026-08-29)

`TEST/oldchatbot_test.md`에 기록된, 실제 홈페이지 규칙기반 챗봇 "독립이"에 입력했던 18개 질문을 새 챗봇(`main.py`)에 동일하게 입력해 회귀 테스트를 실시했습니다. 목표는 **기존 챗봇이 맞췄던 질문은 그대로 맞고, 기존에 실패했던 질문은 개선되는지** 확인하는 것입니다.

**결론**: 기존 챗봇이 맞췄던 7개(#1,5,12,13,14,15,18)는 새 챗봇도 모두 맞추고(회귀 없음), 기존에 실패·부분성공했던 11개(#2,3,4,6,7,8,9,10,11,16,17)는 전부 정확한 답변으로 개선되어 **하위 호환 + 전면 개선**을 확인했습니다. 검증 과정에서 #14(오타가 섞인 "킷보드")가 처음에는 새 챗봇에서도 실패하는 것을 발견해, (a) 동의어 사전에 "킥보드/퀵보드/킷보드" 그룹 추가, (b) "가지고"처럼 우연히 희소해 보이는 일반 동사가 핵심 키워드로 오인되지 않도록 한국어 기능어 불용어 필터를 검색 로직(`main.py`)에 추가하는 두 가지 방식으로 해결했습니다.

**호환되지 않는(=아직 재현하지 못하는) 부분**: 기존 챗봇도, 새 챗봇도 멀티턴(직전 대화 맥락) 처리는 지원하지 않습니다. 이는 아래 "향후 시스템 설계로만 해결 가능한 항목"에 별도로 남겨두었습니다.

## ⚠️ 신규 발견 사항 — 실제 운영 전 확인 필요

- **041-560-0353 번호가 서로 다른 두 서비스에 쓰이고 있음**: `01_관람안내_이용정보.md`의 종합안내센터 표에서는 **유모차·휠체어 대여** 문의번호로, `03_자주묻는질문_FAQ.md`의 통일염원의 동산 항목에서는 **타종 신청** 문의번호로 각각 원본 홈페이지에 기재되어 있습니다. 같은 부서의 대표 내선일 수도 있으나, 서로 다른 장소(종합안내센터 vs 통일염원의 동산)의 서비스가 같은 번호라는 점은 원본 오류일 가능성도 있으므로, 실제 서비스 전 담당 부서에 확인을 권장합니다. 확인 전까지는 두 항목 모두 원문 그대로 유지했습니다.

## 향후 시스템 설계로만 해결 가능한 항목 (문서 수정으로는 해결 안 됨)

아래 2건은 정보 자체는 지식베이스에 이미 존재하지만, **직전 대화 맥락을 이해하지 못해서** 발생하는 실패입니다. RAG 파이프라인의 질의 재작성(query rewriting) 로직으로만 해결 가능하며, 현재 `main.py`에는 아직 구현되어 있지 않습니다.

| 실패 사례 | 필요한 처리 방식 |
|---|---|
| "주차 요금이 얼마인가요?" → (답변 받음) → "주차장 무료로 이용할 수 있는 날이 있나요?" | 직전 답변과 중복되는 후속 질문을 대화 이력을 참고해 자연스럽게 답할 수 있도록, 검색 쿼리 및 응답 생성에 대화 이력을 포함 |
| "안내견도 못 들어가나요?" → "그럼 반려동물은요?" | "그럼"이 가리키는 대상(직전 턴 주제)을 인식하지 못하고 독립 검색되는 문제. 지시어("그럼", "그거", "거기")가 포함된 질문은 직전 턴 주제로 검색 쿼리를 보강하는 전처리가 필요 |

## 데이터 관리 원칙 (지속 적용)

- 이 지식베이스는 스냅샷 시점(2026-08-29) 기준입니다. 요금, 운영시간, 전화번호, 프로그램 내용은 변경될 수 있으므로 정기적인 재크롤링(re-crawl)이 필요합니다.
- 답변이 불확실한 항목은 추측해서 답하지 말고 "종합안내센터(041-560-0771)로 문의해주세요"처럼 안전하게 안내하도록 각 청크에 이미 명시해두었습니다. 새 항목을 추가할 때도 이 원칙을 유지해주세요.
- 전화번호·요금 등 숫자 정보는 챗봇이 원문 그대로 인용하도록 하고, 임의로 반올림하거나 요약하지 않도록 프롬프트에 명시하는 것을 권장합니다.
